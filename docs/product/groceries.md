# KUNDE Groceries 1.0 — DEV/TEST срез (2026-11-21)

Groceries — самостоятельный домен поверх общей платформы: магазины и товары лежат в таблицах Food (`vertical = 'GROCERY'`),
заказы, промокоды, резерв остатков, замены и самовывоз переиспользуются из Food 2.0. Отдельного backend нет.

## Матрица «функция → статус»

| Функция | Статус | Где / доказательство |
|---|---|---|

| Рейтинг товара | Не сделано | отзывы привязаны к заказу/магазину; выдуманных рейтингов нет |

## Проверки (фактически запущены)

- Backend `mvn verify` на PostgreSQL 16: 376 тестов (+10 `GroceriesApiIntegrationTest`), 0 падений.
- Flutter: `analyze --fatal-infos` чисто, 328 тестов (45 Groceries: сервер-фильтры, пагинация, корзина, списки, 320/360/412 dp при тексте 200%, tap-target и label guidelines).
- Визуал: golden-рендеры `mobile/test/features/groceries/goldens/` (Samsung 390 dp) сверены с референсом: фиолетовый hero с фото, город, поиск, быстрые действия, категории, карточка товара. Расхождения: нет фото товаров (эмодзи/иллюстрации), нет рекламного баннера (нет данных), корзина/checkout — существующие экраны Food.
