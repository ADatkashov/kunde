# AI Integration Boundaries

AI is disabled (`aiEnabled=false`); no provider SDK, API key or model call exists. The deterministic demo endpoint was removed because it presented ungrounded text as an assistant.

When approved, add an application-service port and provider adapter behind feature control. The orchestrator may call only allowlisted business APIs with caller authorization and server policy checks. It cannot query a DB/ledger, assert completion without verified state, or take a paid action without a current server-validated preview and explicit user confirmation. D-08 processor/privacy review, evaluation and cost budgets are prerequisites.
