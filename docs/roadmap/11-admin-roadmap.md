# 11 — Admin Portal Roadmap

## Minimum launch surface

1. Strong staff authentication, least-privilege RBAC, scoped access, audit history and separation of duties.
2. Partner/branch verification state and orderable catalog/service-area controls.
3. Searchable order timeline with customer, partner, fulfillment and verified payment status; restricted PII display.
4. Exception/support queue, notes/escalation, policy-based cancellation/refund request and approval flow.
5. Reconciliation export/report and visible unresolved/unknown payment cases.
6. Category/zone/hours kill switches, incident links and configuration change audit.

Users, providers, bookings, disputes, moderation, promotions, advanced analytics and system configuration expand only when corresponding product scope is approved. Never put unreviewed unrestricted database editing in the operator portal. Refund limits and dual-control rules await D-14. Admin acceptance requires permission-negative tests, audit completeness, privacy review, recovery workflow and staff runbook.
