# Architecture Decision Records

ADRs capture proposed technical decisions for review. “Proposed” is not user approval. A decision changes to accepted only after named owner review; retain superseded records and link replacement ADR.

Identity proposal: [ADR-015](ADR-015-proposed-identity-provider.md) adds a portable KUNDE identity boundary and evaluation gates. It remains **PROPOSED**, does not select an IdP, and does not modify accepted ADRs. ADR-009 remains the existing provider-pending authentication decision.
