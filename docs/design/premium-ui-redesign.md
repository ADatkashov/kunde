# KUNDE Premium UI — 2026-11-15

Основание: запрос владельца на полный светлый Flutter-редизайн по первому
референсу, ветка `feature/kunde-premium-ui`, исходный main `420b595`, перед PR актуализирован до `3b66960`.

## Реализация

- Светлая тема независимо от системной, белый фон, изумрудные semantic tokens,
  единые Material-карточки, поля, кнопки, навигация и sheet-поверхности.
- Главная: оригинальный векторный K, горный header Алматы, выбор поддерживаемого
  города, крупный поиск, KUNDE AI «Скоро», объёмная сетка категорий 5 × 2,
  фотобаннер Food, быстрые действия, карточки заведений рядом.
- Food/Grocery: иллюстрированные заголовки, общий каталог с фото из API или
  локальной иллюстрацией, поиск/фильтры/сортировка сохранены. Высота фильтров и
  перенос стоимости доставки адаптированы к увеличенному тексту.
- Корзина/оформление: единая иерархия этапов, карточки позиций, существующие
  пересчёт цены, количество, замены, адреса, оплата DEV, подтверждение сохранены.
- История: иллюстрированные карточки с существующими статусами и переходами.
  Профиль: карточки данных и единые поля; язык/выход доступны в его app bar,
  адреса/согласия/поддержка/партнёрские инструменты сохранены.
- Пять вкладок: Главная / Поиск / Заказы / Сервисы / Профиль. Это решение
  текущего запроса заменяет старые четыре вкладки, сохраняя прямой доступ к
  профилю. Сервисы проверяют `bookingEnabled` так же, как категория на главной.

Backend, API-контракты, capability flags, аутентификация и state machines не
менялись. Недоступные функции не имитируются; синтетические заведения сохраняют
пометку ДЕМО. Нет вымышленных рейтингов, уведомлений или фото заведений.

## Изображения и шрифты

Все home assets локальные: Microsoft Fluent Emoji (MIT), рекламная фотография
Unsplash, оригинальные векторные рисунки, Noto Sans (SIL OFL 1.1) с RU/KK/₸.
Источники и копии лицензий: [mobile/assets](../../mobile/assets/README.md).
Фотографии каталога используются только из существующего HTTPS `imageUrl`;
ошибка загрузки оставляет иллюстрацию и доступ к заведению.

## Автоматическая проверка

Flutter 3.47.9 / Dart 3.13.7 (та же версия, что в CI). Локально: analyze и форматирование чистые; **177 тестов прошли**, включая сравнение 11 новых golden-эталонов без их обновления.

```sh
cd mobile
flutter pub get --enforce-lockfile
flutter analyze --fatal-infos
dart format --output=none --set-exit-if-changed lib test
flutter test
```

- `home_screen_test.dart`: golden главной 360/390/412 dp, RU/KK/EN, 320/390 dp
  при масштабе 100/200%, offline/retry и неактивные категории.
- `food_flow_test.dart`: golden главной с API-карточками и пятью вкладками,
  Food, Grocery, корзины, оформления, пустой/заполненной истории; компоновка
  Food/Grocery на Samsung 360/390/412 dp при тексте 200%; существующий заказ →
  перезапуск → история, фильтры, ошибки и варианты Grocery сохранены.
- `auth_screen_test.dart`: golden профиля, светлая тема при тёмной системной,
  пять вкладок и сохранённые сценарии профиля/входа/выхода.
- `kunde_shell_test.dart`: пять локализованных вкладок, capability gate сервисов,
  48 dp touch targets, вкладки при тексте 200%.

Golden tests используют локальный шрифт приложения и заранее декодированные
assets; тестовые API существуют только под `test/`. Эталоны просматриваются
визуально и затем проверяются повторным `flutter test` без `--update-goldens`.
Статический premium-аудитор выполнен; он ориентирован на web и не заменяет
Flutter analyze/widget/golden проверки.
