**Hierarchy:** location → global search → AI → supported categories → active transaction → sourced recommendations. Greeting is optional; no invasive personalization. Main CTA is search or category discovery, not promotion. On compact widths, category grid remains two columns and recommendations stack. Skeleton mirrors these blocks; no-supply state invites a different area; offline state marks cached cards stale and disables order entry.
