# Product or Service Detail — C-12/C-13

```text
┌ ‹ Item or service name       ♡ ┐
│ [Image / gallery]               │
│ Business name · availability    │
│ Price: fixed / estimate / quote │
│ Description and inclusions      │
│ Options / modifiers / duration  │
│ Staff or resource (if needed)   │
│ Stock / slot freshness          │
│ Terms · cancellation · support  │
│ [Add to cart] OR [Choose time]  │
└────────────────────────────────┘
```

Product path shows options, quantity, stock and add-to-cart. Service path shows scope, duration, price basis and date/staff selection; quote-required home/auto service starts request, not payment. Avoid ambiguous “Book now” if provider confirmation is pending. Screen reader announces price type and availability status.
